为什么做它

自我管理工具的三个老问题

数据散落

待办、打卡、记账、笔记各在一个 App。没有一处能同时看到这周学了什么、花了多少、睡得怎么样。

AI 只给建议

和聊天机器人聊完一套计划，还得自己一条条抄进各个 App。下次再聊，它已经不记得你了。

通用助手不够专

一个助手什么都管，提示词越写越长，哪方面都不够专业，也没法给它划定能动哪些数据。

团队与权限

每位智能体只碰它该碰的数据

权限在智能体编辑页勾选。智能体只能读到被授权的数据，越权的动作会被拒绝。你可以新建任意多位智能体，或者用模板一键创建英语陪练、读书搭子、求职顾问、饮食规划师。

动作协议

AI 说完就能做，但做什么由你把关

好的，午饭记上了，周报排到明天上午。

```actions
[{"type":"add_expense","amount":35,
  "category":"餐饮","note":"午饭"},
 {"type":"add_task","title":"交周报",
  "due":"2026-10-13"}]
```

智能体在回复末尾附一段结构化动作，平台解析后写进你的数据。任何能输出文字的模型都能用，不依赖某家的工具调用接口。

权限

只开放被授权数据域的动作，越权会被拒绝并标红。

去重

多位智能体并行时，同一笔账、同一个任务不会重复记录。

确认

可关闭「自动执行」，每个动作都要你点「执行」才生效。

留痕

谁在什么时候做了什么，都记在首页的团队动态里。

自己定义

能改的，基本都能改

智能体

名称、图标、一句话角色、系统提示词、服务商、模型、思考强度或温度、数据权限、启用与停用。编辑页能预览它实际收到的完整提示词。

工作流

步骤顺序、每一步由谁做什么、汇总人、手动 / 每天 / 每周触发。

模型

每位智能体可以用不同的模型。比如总管用 Claude，记账用便宜的 DeepSeek，私密日记交给本地 Ollama。

能力

在 SP.ACTIONS 里加一项就是一种新动作，权限和提示词自动生效。

隐私与边界

数据在你手里

本地优先

默认数据只存在浏览器本地。API Key 只存本机，请求直接发往你选的模型服务商。

随时带走

一键导出 JSON 备份；开启同步后，服务端也只是一个 JSON 文件。

还没做到的

定时工作流只在页面打开时触发，错过当天会补跑一次。服务端定时执行、语音输入和按条目合并同步在后续计划里。
