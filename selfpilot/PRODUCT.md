# 自驱舱 SelfPilot · 产品介绍

> 一支只为你工作的智能体小队。管学习，也管生活。

## 一、为什么做它

自我管理的工具很多，但用起来有三个老问题：

1. **数据散落**：任务在待办 App，习惯在打卡 App，记账在另一个 App，学习笔记又在别处。没有哪个地方能同时看到「我这周学了什么、花了多少、睡得怎么样」。
2. **AI 只给建议，不落地**：和聊天机器人聊完一套计划，还得自己一条条抄进各个 App。下次再聊，它已经不记得你了。
3. **通用助手不懂你**：一个助手什么都管，提示词越写越长，哪方面都不够专业。

自驱舱的做法是：**一份属于你的数据，加上一组分工明确、各有权限的智能体**。它们读的是你的真实数据，说完就能直接动手记录，而且你可以随时改它们的设定。

## 二、产品定位

| | |
|---|---|
| 用户 | 自己（单用户、自托管） |
| 核心价值 | 用自然语言管理学习与生活，AI 直接读写你的数据 |
| 关键词 | 多智能体、可自定义、本地优先、零依赖、可落地 |
| 形态 | Web 应用 / PWA，可选轻量服务端 |

## 三、智能体团队（默认 6 位，可增删改）

| 智能体 | 职责 | 默认数据权限 |
|---|---|---|
| 🧭 总管 | 理解意图、分派任务、汇总结论 | 全部 |
| 📚 学习教练 | 学习计划、费曼讲解、出记忆卡 | 任务、目标、笔记、记忆卡、长期记忆 |
| ⏱️ 时间管家 | 排优先级、日/周计划、时间块、重新排期 | 任务、目标、长期记忆 |
| 🌿 健康管家 | 睡眠、运动、饮食、习惯打卡 | 习惯、日记、长期记忆 |
| 💰 财务管家 | 记账、预算、消费分析 | 账本、目标、长期记忆 |
| 🪞 复盘导师 | 日记、情绪觉察、每日/每周复盘 | 日记、目标、任务、习惯、长期记忆 |

另有「英语陪练」「读书搭子」「求职顾问」「饮食规划师」模板，一键创建。也可以从空白开始写自己的智能体。

**每个智能体都可以自定义**：名称、图标、一句话角色、系统提示词、模型服务商、模型名、思考强度/温度、数据权限、启用/停用。编辑页能预览它实际收到的完整提示词。

## 四、多智能体怎么协作

| 方式 | 怎么用 | 发生了什么 |
|---|---|---|
| 圆桌会议 | 新建「圆桌」对话，直接说事 | 总管先判断该谁来答（0~3 位），专家**并行**发言，再由总管去重、排优先级、给出结论 |
| 单聊 | 在智能体卡片点「单聊」 | 一对一深聊，比如和学习教练讲透一个概念 |
| @点名 | 任何对话里输入 `@健康管家` | 跳过路由，指定的智能体直接回答 |
| 互相请教 | 智能体自己发起 `ask_agent` | 比如时间管家排计划时请教学习教练该学多久，最多两层，防止来回踢皮球 |
| 工作流 | 「晨间启动」「晚间复盘」「周复盘」等 | 按步骤依次调用智能体，后一步能看到前面所有输出，最后汇总；可定时 |

### 动作：AI 说完就能做

智能体在回复末尾附上一段结构化动作，平台解析后写进你的数据：

```actions
[{"type":"add_expense","amount":35,"category":"餐饮","note":"午饭"},
 {"type":"add_task","title":"交周报","due":"2026-10-13"}]
```

共 12 种动作：新建/更新任务、新建/更新目标、新建习惯、习惯打卡、写日记、写笔记、出记忆卡、记账、写入长期记忆、请教同事。

三道保险：

- **权限**：智能体只能读、写被授权的数据域，越权动作会被拒绝并标红。
- **去重**：多位智能体并行时，同一笔账、同一个任务不会被重复记录。
- **确认**：可以关闭「自动执行」，每个动作都要你点「执行」才生效。

每次操作都会写进首页的「团队动态」，能看到谁在什么时候做了什么。

## 五、一天怎么用

| 时间 | 场景 |
|---|---|
| 07:30 | 「晨间启动」自动运行：时间管家挑今天最重要的 3 件事，学习教练排 30~60 分钟学习，健康管家给一句提醒，总管汇总成简报，显示在首页 |
| 白天 | 在首页输入框随手说一句：「打车 28」「提醒我周五前交报告」「今天跑了 5 公里」，小队自动记账、建任务、打卡 |
| 学习时 | 和学习教练单聊一个知识点，关键概念自动变成记忆卡，按 SM-2 间隔重复安排复习 |
| 21:30 | 「晚间复盘」：复盘导师根据今天的完成情况写复盘，存进日记 |
| 周日 20:00 | 「周复盘」：四位管家各自汇报，复盘导师总结问题模式，把下周重点加成任务 |

## 六、数据模块

今日 · 对话 · 任务 · 目标（含关键结果）· 习惯（14 天打卡格）· 日记（心情/精力）· 笔记（Markdown）· 记忆卡（SM-2 复习）· 账本（月度分类统计）· 长期记忆（所有智能体共享的「关于我」）

所有模块都能手动增删改。不接 AI 也能当一个完整的个人管理工具用。

## 七、技术方案与落地

- **前端**：原生 HTML/CSS/JS，无框架、无构建，约 2000 行，支持手机布局、深色模式、PWA。
- **模型层**：Anthropic Messages API（浏览器直连、SSE 流式、思考强度、拒绝时服务端兜底）与 OpenAI 兼容 Chat Completions（DeepSeek / 通义 / Kimi / 智谱 / OpenAI / Ollama / 自定义）。另带一个离线模拟模型，不填 Key 也能完整体验。
- **服务端（可选）**：`server.mjs` 零依赖，负责静态托管、模型请求转发（只允许 https 或本机 http）、多端同步（乐观锁防覆盖、冲突时让你选、每日快照）、令牌鉴权。
- **部署**：GitHub Pages / 本机 `node server.mjs` / Docker 一行命令。
- **数据**：浏览器本地存储，可导出/导入 JSON 备份；开启同步后存到服务端 JSON 文件。

## 八、隐私

- 默认不上传任何数据。API Key 只存本机，请求直接发往你选的模型服务商。
- 智能体只看得到你授权给它的数据。
- 自托管服务端需设置访问令牌；数据是一个 JSON 文件，随时可以拿走。

## 九、已知限制与后续计划

| 现状 | 计划 |
|---|---|
| 定时工作流只在页面打开时触发（错过当天会补跑一次） | 服务端定时执行 + 推送通知 |
| 同步是整份数据的版本比较，两端同时改时需要手动选一份 | 按条目合并 |
| 输入以文字为主 | 语音输入、拍照记账 |
| 数据只在自驱舱内 | 导入日历、导出到 Notion/Obsidian |
