# Équipe：个人多 Agent 管理平台

把学习和生活拆给几位各有分工的 Agent，自己当制片人，统一排期、派活和复盘。

**在线体验：** https://dingyue-xu.github.io/side-projects/equipe/

## 功能

- 今日通告单：每位 Agent 一行，列出今天到期、逾期和进行中的任务；进度条、快速添加、习惯打卡、今日随记
- Agent 团队：名字、职责、工作指令、颜色都可自定义，内置 6 个模板，可指定主理人
- 任务与习惯：负责人、截止日、优先级、状态；最近 7 天打卡方格和连续天数
- 对话与圆桌：单聊，或让几位 Agent 依次发言、由主理人收束；回复可一键转成任务
- 复盘：晨会简报、圆桌纪要、周复盘和随记统一归档

## 两个版本

| 版本 | 数据 | AI |
|---|---|---|
| 这里的公开演示版 | 保存在访问者自己的浏览器（localStorage），可导出和导入 JSON | 未接入，相关按钮不可用 |
| Claude 内运行的版本 | 云端存储，跨设备同步 | 单聊、圆桌、晨会、拆解目标、周复盘全部可用 |

## 技术

单文件，原生 HTML / CSS / JavaScript，无构建步骤、无依赖。同一份代码在检测到 Claude 运行环境时使用其存储和模型能力，否则回退到浏览器本地存储。
